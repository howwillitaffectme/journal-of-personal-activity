My try of google ai studio to create something with 0 lines of code. The result after on the order of 100 prompts is here. 

This is a Journal of Personal Activity. It is designed to track activities defined by the user, includes both binary and scalar values, atmospheric tracking, daily notes and monthly evidences of presence. 

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
